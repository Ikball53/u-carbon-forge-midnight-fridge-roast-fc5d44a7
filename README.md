# Midnight Fridge Roast

A smart fridge that locks itself after midnight gets roasted in a single line: the leftovers end up with better boundaries than their owner. The joke lands on the twist that the fridge, not the person, is the one setting limits.

Run `python3 main.py` to write the one-line entry to `/output/entry.txt`.
